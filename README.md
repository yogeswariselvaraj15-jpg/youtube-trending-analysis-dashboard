# youtube-trending-analysis-dashboard
Power BI dashboard project for analyzing YouTube trending videos, views, likes, comments, engagement, and channel performance. 

# YouTube Trending Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes YouTube trending video data to identify:
- Video performance
- Audience engagement
- Category-wise trends
- Channel performance

## Tools Used
- Power BI
- Excel / CSV Dataset

## Dashboard Features
- KPI Cards
- Monthly Views Trend
- Category-wise Analysis
- Channel Performance Analysis
- Interactive Filters (Slicers)

## Key Insights
- Total Views: 4B+
- Total Likes: 191M+
- Total Comments: 27M+
- Total Channels: 752
